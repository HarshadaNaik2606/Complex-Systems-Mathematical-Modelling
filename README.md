# Mathematics and Computational Methods for Complex Systems

This repository contains computational problem sets developed for the course  
**Mathematics and Computational Methods for Complex Systems**.

The project demonstrates the application of mathematical theory alongside
computational techniques to analyse and verify properties of complex systems
using Python.

---

## Overview

The assignments focus on applying linear algebra and numerical methods to study
matrix transformations and their properties. Mathematical concepts are supported
by computational verification to ensure correctness and deepen understanding
of system behaviour.

The notebook combines theoretical reasoning with practical implementation
using Python and scientific computing libraries.

---

## Topics Covered

- Matrix transformations
- Eigenvalues and eigenvectors
- Linear independence of vectors
- Basis construction and diagonalisation
- Numerical verification of mathematical properties

---
